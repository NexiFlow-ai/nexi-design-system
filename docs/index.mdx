Every Nexi application is built from one kit and one set of rules. This section is that system, written once: the
pages are generated from the Design System Register, and every component is shown as it really renders, in the
**component workshop** — a living catalogue of every component in every state, in Light and Graphite, in English and
Ukrainian.

## How to read a component page

Each page carries the register id (`DS-3001` and the like), the kit export a screen imports, the sentence that *is*
the component's contract, the list of its states, and the stories that prove it. A story embedded on the page is the
real component rendered from the same code the applications ship — not a picture. *Open in the workshop* shows the
same story with the theme, language and density switches.

## The rule in one sentence

A screen is composed of registered components; a new idiom proposes a register row before code; a component without
a story does not exist.
