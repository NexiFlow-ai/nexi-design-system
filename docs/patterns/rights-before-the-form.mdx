A form that ends in a write the person may not do is never drawn: the surface asks the policy decision point first and renders the shape the answer allows — *use the shared one* · *add a key* · *ask an administrator* — and the request to a granter is a **first-class shape, not an error**. The rights answer is read once per surface, fails closed (no answer → no key field, a *Retry*), and the server re-checks on every write. What the person prepared is kept as a draft on the request object, never lost at the hand-over. Hiding a field grants nothing.
