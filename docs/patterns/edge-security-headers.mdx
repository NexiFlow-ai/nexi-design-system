Every suite host answers the browser with the same security contract, set once at the edge (Caddy `(edge_headers)`, `deploy/gcp/platform/compose.caddy*.yml`) and never re-stated in an app: HSTS six months with subdomains · `nosniff` · `Referrer-Policy: strict-origin-when-cross-origin` · a `Permissions-Policy` that denies camera · geolocation · payment · usb · FLoC and keeps the microphone to `self` (the composer's mic, a conversation path) · `X-Frame-Options: DENY` on every host but NexCare, whose widget frame is embeddable per installation through its own `frame-ancestors` · the upstream's `Server` / `X-Powered-By` banners stripped. The strict content-security policy is **enforced by every app from its `proxy.ts`**: one builder, `@nexus/app-shell/csp`, mints a 16-byte nonce per request, stamps the policy on the request (Next nonces its own scripts) and on the response, and the root layout hands the nonce to the one inline script of the suite (`THEME_BOOT_SCRIPT`); `script-src 'self' 'nonce-…' 'strict-dynamic'`, `frame-src 'self'`, an app's extras as **named arguments** only (NexChat/NexCore `wss:` · NexMap its basemap origin and `data:` on connect · NexCare `frame-ancestors` per installation and the fixture host's flipped dev origin on `frame-src`); `'unsafe-eval'` on a `next dev` server only. The edge keeps the same policy **report-only** with a same-host `report-uri` until the first hosted window is read (G-27); the reports of both land on core-api's door as one sanitised line each — path · origin · directive, never a query, a fragment or a token — and leave the stack nowhere. Every edge value is set-if-absent so an app's own header wins. A screen therefore never carries an inline `<script>` without the nonce, never an `<object>`, never a third-party origin the policy does not name.
