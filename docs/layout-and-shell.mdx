One shell, one page frame, one way to go two levels deep, one right-hand panel. A new application starts from `apps/_template` and inherits every row here without writing layout code.

## DS-2001 — The shell grid

`NexusShell` draws the skip link, the offline strip, `<main>` and the dock. The app's own left navigation (if any) is 248 px with a 52 px rail when collapsed; the collapse handle is centred on the divider (32 × 44 px, 200 ms). With no app navigation the shell draws its own 48 px rail (`dock="shell"`).

Components: `@nexus/app-shell#NexusShell` · `@nexus/app-shell#ShellDock`

## DS-2002 — The dock

Language · Apps · notifications · the user menu (Connected accounts, Settings, Sign out) sit in the `ShellDock` at the bottom of the left navigation (`dock="app"`) or in the shell rail. Menus open upward or beside the rail, follow the WAI-ARIA menu pattern and return focus to their trigger. `Alt+A` opens the launcher suite-wide.

Components: `@nexus/app-shell#ShellDock`

## DS-2003 — The launcher

Static tiles for the applications (Chat · Spin · VibeBan · BI · Graph · Core) and a tile for each module the organization enabled (Map · Care · Forge); a disabled module is absent, never greyed. Each tile carries its app accent (DS-1004) and a one-line description; `resolveAppHref` sends cross-app links to the right origin.

Components: `@nexus/app-shell#AppLauncher` · `@nexus/app-shell#NEXUS_APPS`

## DS-2004 — Page frame widths

Content sits in `PageFrame`: `standard` (max 1320 px — people, settings, detail pages) or `wide` (overview, matrix, audit, executions). 32 px of air above the header line; the body starts 16 px under the tabs.

Components: `@nexus/ui/workbench#PageFrame`

## DS-2005 — The header line

Back arrow (icon, labelled) · title (ellipsis at 46 %) · ≤ 3 chips · Ask bar · ≤ 2 buttons + `⋯` on one 36 px row; under 720 px chips and actions wrap under the title. NexCore and NexChat keep their stacked frame (eyebrow · title · lead) for their own detail pages; every other app renders `layout="dense"`.

Components: `@nexus/ui/workbench#PageLine` · `@nexus/ui/workbench#PageFrame`

## DS-2006 — Two levels, never tabs under tabs

The first level of a page is one underline tab row (`UrlTabs` / `LocalTabs`, state in `?tab=`). The second level is a left column of sections (`SideNav` in a `SideNavLayout`, 200 px, `aria-current`). A segmented control may switch views of the same data (list / board) and sits with the filters, never styled as tabs.

Components: `@nexus/ui/workbench#UrlTabs` · `@nexus/ui/workbench#LocalTabs` · `@nexus/ui/workbench#SideNav` · `@nexus/ui/workbench#SideNavLayout`

## DS-2007 — The Inspector column

Reading and editing one thing happens in the right-hand `Inspector`: 360–640 px, resizable by a keyboard separator, width persisted per app; Esc closes and focus returns to the opener. Creation opens the same panel empty (`FormInspector`). Under 720 px it becomes a sheet. There is one Inspector on a page.

Components: `@nexus/ui/workbench#Inspector` · `@nexus/ui/workbench#FormInspector`

## DS-2008 — The Ask surface

Every app's header line carries the Ask bar: the minimised NexChat composer that sends to chat-api as a Project of that app and offers the hand-off chip and *Back to &lt;app>* return. An app never builds its own chat input.

Components: `@nexus/ui/ask#AskSurface`

## DS-2009 — Theme and locale are attributes of `<html>`

`data-theme` (`light` · `graphite`) and `lang` (`en` · `uk`) are set on `<html>` by the shell from the person's device preference; `THEME_BOOT_SCRIPT` applies the theme before hydration. Graphite ships behind the token audit (`GRAPHITE_ENABLED`); the workshop renders it regardless so the audit has a place to happen.

Components: `@nexus/app-shell#useTheme` · `@nexus/app-shell#THEME_BOOT_SCRIPT` · `@nexus/i18n#LocaleProvider`

## DS-2010 — Settings and shortcuts are sheets

Appearance, language, notifications and the keyboard reference open as `SettingsSheet` / `ShortcutsSheet` from the dock — one 400 px drawer, not a settings page per app. App-specific settings live on that app's Settings tab, under the same frame as everything else.

Components: `@nexus/app-shell#SettingsSheet` · `@nexus/app-shell#ShortcutsSheet`
