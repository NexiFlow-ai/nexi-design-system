**DS-6701** · `apps/factory/src/components/parts/ReadinessGates.tsx#ReadinessGates` · proposed

The engine's verdict on one production order, said as a list of gates: a verdict line (*Ready* · *Ready with risk* · *Blocked* · *Unknown* — the verdict is a tone of `Chip`, DS-3003, never colour alone; the count *n of 7 verified*), then one row per gate in policy order — glyph · the gate's name · its one-sentence reason · *required* / *optional* — `verified` ✓, `failed` ✕ with the reason the fact fails, `unknown` ? with the fact that is missing and the source that did not answer. Deterministic: the component only renders what the evaluator computed; a missing fact never reads as *ready*; a done order shows *not evaluated*. Not a kit duplicate: no kit export shows a verdict over a fixed list of pass/fail/unknown rules. S2: the block is **live** — *Re-evaluating* keeps the last record visible, dimmed, while a `role=status` line says *Evaluating…* and announces the new verdict when a different record arrives; *Changed by* names the gate and the fact the engine recorded; the cause of the run (*after a source sync* · *asked by a person* …) closes the foot.
