Settings › Field policy: read-only. One line names the relations that read the financial bucket (`factory.lead` · `factory.admin`) and the action the PEP checks (`factory.financial`); one row per record type lists the restricted fields — the built-in ones (*unit_cost*, *customer_label*) with *built-in*, the custom fields the schema marked *financial* with *custom field* (Settings › Fields). A record type with nothing restricted says *nothing restricted*. Nothing here is editable: the relations are NexCore's, the fields are the schema's — the page is the explanation of what a planner does not see and why, never a switch; the `Restriction` under it says so. Not a kit duplicate.
