**DS-6901** · `apps/chat/src/components/builders/AddToolDoor.tsx#AddToolDoor` · adopted

The one door an agent's *Tools* tab opens on *Add tool*: an `Inspector` (DS-3031; a full-screen sheet under 720 px — (a)) listing what the organization already has in three groups — *Connected* (a healthy connection, shared or the person's own) · *Platform* (`nexus-base`) · *Custom* (this organization's imports, requests included) — as `RowList` rows (DS-3035): `ProviderMark` (DS-3066) · name · chips (*Read-only* / *Makes changes* · *Approval* · a `≤ ceiling`) · exactly one trailing control the server allowed: *Add* · *Connect ⟨provider⟩ →* (a user-delegated consent) · a reason chip with no button (above the ceiling, blocked) · *Awaiting review* (the person's own request). A `SearchField` only past 12 rows; the Ask line (*What should ⟨agent⟩ be able to do?*, DS-4001) arrives with S4 under. The quiet way out is an `ActionRow`: *Connect a new API* · *Ask an administrator*. Never a key field here. Not a kit duplicate: the kit has the Inspector and the rows; the grouping, the one-control rule and the preflight-shaped actions are NexChat's.
