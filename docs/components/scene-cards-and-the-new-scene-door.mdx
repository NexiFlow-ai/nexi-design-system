The library as cards: a card earns its place over a table row by carrying the scene's **picture** — `ScenePreviewThumb` draws the footprints of the current version from the same rows the server lists, so a scene is recognised before it is read; title · project · template · updated · counts · role (`Chip`) complete it; the whole card opens for a pointer, the title link is the keyboard and screen-reader path. The library's one header line is title · count · *New scene*; the search, the Project filter and the cards | table control exist only past one screen. An empty library *is* the New scene door: NexChat's one-line composer on the stage with the starting points one quiet row beneath — no form, no mode switcher; `/forge/new` is the same door with `←` and the Project carried over. Built on `Chip` (DS-3003), `PageLine` (DS-2004), `DataStateView` (DS-7005); not a kit duplicate — the kit has no card with a picture and no door.
