**DS-4003** · `@nexus/app-shell#ConnectedAccountsDialog` · adopted

A connection belongs to the person, not to an app or a Project, so the dialog is the shell's — *Connected accounts* in the account menu — a `Sheet` (DS-3067, `wide`) over `GET /synapse/connections ?owner=me` and the integration catalogue. One `SheetRow` per integration the person may delegate: the account, the granted scopes by their labels, the health and the last use as text — never a token, a code or a credential reference (the server returns none). *Reconnect* (expired — the same consent flow as the just-in-time card, in a popup) and *Disconnect* are 28 px buttons at the row's right; *Disconnect* asks once, inside the sheet, as the kit's `ActionPanel` with `danger` (DS-7004) naming the integration. Offline the list reads and every action is disabled. Visibility of the menu item is the host's hint; authorization is the server's on every call.
