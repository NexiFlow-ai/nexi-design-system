**DS-5002** · `apps/chat/src/components/thread/GoalCard.tsx#GoalCard` · adopted

The goal is the eighth executor on the same turn card with the goal's parts in its slots: the plan with Accept · Change · Not now, the latest result as the body with earlier results folded beneath, the coverage line at completion, and the doors (view the plan · stop · pause · resume · open). The turn that opened the goal ends `done` while the goal continues; every later moment updates the same card — never a second card. The edges have no card of their own: a goal in another Project is not found exactly like any other not-found; an archived thread's card is read-only; a question to the running goal is prose in the thread. S8 adds two slots, no new card: the **Situation strip** above the plan — what NEXUS already holds about the subjects of the ask (NexSales · Vibeban · NexCare · artifacts · sources · the people on those records), each line a source word, the record's label and a door; one honest line naming the party when nothing was found; *not checked* for a source that did not answer; a record the person may not read is not a line and not a count — and the **Next line** at the proposal and at completion: 1–3 doors drawn only from found records, installed capabilities or the creation doors (*Create the account in NexSales* · *Add this request to Vibeban*), the colleague suggestion as a sentence then *Ask ⟨name⟩*, and the one question *What would you like me to do next?*. A drafted artefact's approval ask shows its security table (reads · writes · reaches) and the approval-required line when it reaches out.
