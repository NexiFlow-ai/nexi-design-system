**DS-6914** · `apps/care/src/components/portal/PublicVerify.tsx#PublicVerifyStep` · proposed

The public support door's verification for a member of a suspended organization: *your organization e-mail* → *Send code* → one neutral line *If this address belongs to an organization on NEXUS, a code was sent* — identical whether the address is known or not → a six-digit code → *Verify* → *You are speaking as ⟨organization⟩ — not signed in* with the line that no content and no balance is available here. Three wrong codes → *Too many attempts — try again in 15 minutes*. Nothing tenant-specific is said before verification. Rendered inside the care widget's public portal.
