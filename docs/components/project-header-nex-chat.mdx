One 52 px row and nothing else: `● ⟨Project⟩ ▾ · CLASSIFICATION / ⟨chat title⟩`. **No builder tabs**: the Project's areas are not navigation for the people who talk here. The name menu carries *Project details · View artifacts · N · Automations · N* *· Configure project…* (owners and editors only, hidden — never greyed — until the role is known; `aria-disabled` offline) *· Pin · Archive project…* (owner). A Personal chat shows *● Personal* with no classification and *Pin* alone. narrows DS-2005's NexChat exemption to this header. Not a kit duplicate: the header line of a conversation, not of a resource page.
