**DS-6102** · `apps/sales/src/components/parts/SaveLadder.tsx#SaveLadder` · adopted

The honest state of one write, in the log composer's footer (DS-6107; a FormInspector's footer elsewhere — amended 2026-10-11): draft · saving · waiting for ‹provider› · pending approval (names the approver) · saved (said only when the source confirmed and returned an id) · rejected (names the field) · conflict (mine · theirs; *Keep mine* · *Take theirs* · *Merge*) · reconciling · not saved (*Try again*) · ‹provider› unavailable · denied (read-only record type). A dot + sentence; `role="status"`, polite for the quiet states, assertive for the ones that need a hand. Not a kit duplicate: `EditBar` (DS-3033) has editing/saving only; the ladder is the write-through contract of a system of record.
