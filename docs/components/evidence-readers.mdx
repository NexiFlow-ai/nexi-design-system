The readers of what a run produced, each a door from a row or a bar, never a page of its own: `ArtifactsGallery`; `VersionDiffPanel`; `ProcessingConfigInspector`; `EntityExplain` (where an entity's relations come from, grouped by kind, the documents of an edge — S11c); `TablePanel` (a table's publish-as-dataset door — the series v1 · v2, verified, the address, revoke keeps the row — S7); `DoorImage` (an image that comes through a door with the credential — loading · failed · bytes). Each names the restriction a reader lacks as a `Restriction` line, never a greyed button. Built on `Inspector`, `Facts`, `DataTable`, `ActionRow`/`ActionPanel`, `States`; not a kit duplicate — the kit has no artifact, no version, no configuration, no dataset series.
