**DS-6603** · `apps/core/src/components/channels/ConnectedChannels.tsx#ConnectedChannelsPanel · ChannelRow` · adopted

The *Connected channels* tab of the person's Account: one `ChannelRow` per messenger — a glyph · the provider's name · its state as `StatusDot` (connected · not connected · waiting for Telegram · unreachable · disconnected) · the facts of the link (the account as the messenger shows it, never a numeric subject · since · last active · the organizations · the current project) · the one action the state allows: **Connect** (the only primary) · **Disconnect** with the confirmation in place · *Open Telegram* with the minutes left while a request is pending · nothing while revoked. Then the notification toggles per kind (`Switch`) and the quiet hours (two compact `Select`s) — the S5 contract drawn now. The row reused `readOnly` is the People inspector's panel (`PersonChannelsPanel`): the admin sees that a channel exists and its state, never the chat, and **Revoke** is the panel's own. No token or link secret is ever printed. Not a kit duplicate: no kit export shows an identity link with its one action.
