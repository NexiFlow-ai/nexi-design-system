**DS-6906** · `apps/chat/src/components/builders/ConfigureHub.tsx#ConfigureHub · AutomationsTable.tsx#AutomationsTable · ToolsScreen.tsx#ToolsScreen` · adopted

The builders' one place for a Project's resources: a `PageLine` breadcrumb *← ⟨Project⟩ · Configure* with the trailing link *Available from the organization · N →* (NexCore's catalogue, nothing copied), a `LocalTabs` row **Agents · Skills · Flows · Tools · Automations**, the `←` returning to the chat the door was pressed on, and the existing screens unchanged as the bodies (an agent keeps its eight-tab detail; the Studio its focus mode; routes kept). *Tools* is the same projection the door reads (DS-6901) as a page: the three groups, a `⋯` of only what the person may do, the two doors *Connect a new API* · *Ask an administrator*, the Track A setup page as the tab's body. **The row (, S3 — `APPROVED UAT-1 (EPIC-045 S3)` 2026-11-01 16:50) is one line:** mark · name · *· N actions* (the names when three fit, the count otherwise) · *· N agents* only when > 0 · the state word **only where it differs from the group's default** (*Connected · shared* under CONNECTED and *Always available* under PLATFORM say nothing; *yours* · *Not connected* · *Awaiting review …* · *Needs changes …* with their links) · **the acts as icon buttons**. The effect · *Approval* · `≤ ceiling` chips are the Inspector's (DS-6908), never the row's. **PLATFORM is one disclosure** — *Platform · N — always available*, collapsed until pressed or searched — whose rows carry the **Lucide glyph of their kind** in the mark square (`KindMark`: actions · artifacts · dataset · web · flows · goal · graph · …), never a monogram. **A barred row** (above the ceiling · blocked by governance) is **last in its group with one reason chip in the server's words and nothing to press**. No column grid: the name and the meta share the line and truncate; the trailing cell takes what it needs; below 720 px it may wrap under the name. **The acts are icon buttons in three fixed columns** (`+` *Add to an agent* · `▷` *Try it* · `↗` *Open in Core*; ✎ *Edit request* · ✕ *Cancel request* on a request row) — only the acts the server granted, each named (tooltip and accessible name), always in the tab order, quiet until the row is hovered or focused; the `⋯` menu is gone from this row (the owner, UAT-1 (S3)). *Automations* lists the Project's automations (name · schedule in words · face · last run · owner · *Pause / Resume · Open* · *Enable · Needs changes*) with *+ New automation*; **every member** reaches the same rows from the name menu under a reduced chrome — *← ⟨Project⟩ · Automations*, no other tab, no action. A viewer on any other tab's URL meets the existing 403. Not a kit duplicate: the kit gives the line and the tabs; the hub is the composition one app owns.
