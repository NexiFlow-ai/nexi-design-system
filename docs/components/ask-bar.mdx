**DS-4001** · `@nexus/ui/ask#AskBar` · adopted

NexChat's composer line minimised into a host app's header: `+` (attach) · the text field with the app's own placeholder · the mic · `↑` (send) / Stop while running; the panel toggle with its unread dot when an answer arrived closed. One line, the control height of the header (DS-1004), never a second chat input in any app (DS-2008). Offline disables send and says so in the field; disabled is a state, not a hidden bar.
