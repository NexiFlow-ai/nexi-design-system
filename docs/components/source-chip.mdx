Where a record lives and how fresh the copy is, next to its title: `NEXUS` for a native record; *from ‹provider› · ‹age›* for an external one read moments ago; *stale · ‹age›* when the last read is old; *‹provider› unavailable* when the source does not answer. Built on `Chip` (DS-3003) with the four semantic tones; glyph + text, never colour alone; the tooltip carries the exact verification time. Not a kit duplicate: the kit's Chip has no notion of provenance or age.
