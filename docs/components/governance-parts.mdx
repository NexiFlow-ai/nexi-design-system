The classification chip (public · confidential · dsk · secret · top_secret — tone + the word), the record status dot (a trace record's lifecycle word), and the trace Inspector's two halves: the span tree (turn → run → call, a time bar per span, container spans fold) and the span detail (the record as fields — refs · statuses · timings · counts · digests, never content; payloads fetched only when opened, redactions named, classification shown; `denied` and `capture off` are honest rungs). Built on `Chip` · `StatusDot` · `Inspector` (DS-3030). Not a kit duplicate: the kit has no span tree.
