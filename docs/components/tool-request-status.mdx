What *Send for review* leaves behind, and the bell's deep link — the body of the request's page: the meta *requested by you · ⟨time⟩ · REQ-⟨id⟩*; the connection line with a `StatusDot`; one line per tool; an `ActionRow` of what the person may do (*Edit request · Cancel request · Done*; *Send again* after a note; *Start again from the draft* when expired; an administrator's own setup ends in *Enable N read actions* — (a)). Another person's request is *not found*. Not a kit duplicate: a status page of one governed object, not a detail Inspector.
