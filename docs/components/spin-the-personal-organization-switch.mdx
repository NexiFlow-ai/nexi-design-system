**DS-6923** · `packages/ui/src/ask/RoomSidebar.tsx#WorkspaceSwitch` · adopted

One identity holds a **personal** workspace and every organization that bound it. The switch is a row under the brand — the workspace's face (a round one for *Personal*, a square one for an organization), its name, *Personal* / *Organization* in small type, a chevron — drawn **only when there is more than one workspace**: *Spin is first a chat for individuals; the switch appears when the person's company runs Nexi Spin*. Its menu lists *Personal* first, always, then each organization with its unread count while another is open, the open one checked, and *Join an organization…* last (Buzz's redemption behind it). Switching changes the rooms, the people **and** the organization of every Nexi turn (the `channels.spin` row of that organization, S2) — the host does that; the row only says which one is open. The phone draws the same menu from the drawer's header (S4, one experience on both clients).
