**DS-6708** · `apps/factory/src/components/parts/FieldSchemaEditor.tsx#FieldSchemaEditor` · proposed

Settings › Fields: the tenant's custom fields, one record type at a time (a `Select` of the seven importable kinds), as rows — key · label en · label uk (both, nothing exists in one language) · type (string · number · boolean · date · enum) · required · *financial* (the value lands in the bucket only `factory.financial` reads) · the enum's options. The version line says *v2 · saved 3 d ago by Olena*. Editing is the `EditBar`'s: *Edit* wakes the rows, *Add field* appends one, *Save* writes **a new version** — the old one is never changed; a key must be `[a-z][a-z0-9_]*` and unique and an enum needs an option — the row says so before the service does (a `role=alert` beside the input), the service's refusal is said on the bar. A reader sees the fields and a `Restriction`, never a disabled control. Not a kit duplicate: the kit has no notion of a versioned schema with a sensitivity per field.
