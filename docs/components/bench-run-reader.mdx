The Runs area's bench pages: **the list** `/graph/runs/bench` — every benchmark run the harness published into this Project, newest first, a row = when · the run with its chips · corpus hash (the policy pair in its title) · questions · the numbers; the arm and corpus filters return past twelve runs; a row opens **the run page** `/graph/runs/bench/{run_id}` — one header line (back · *Run* and the id · chips · when), the seven numbers as the `nexus-cc-span-stats` fact row (questions · fact coverage · cite@k · false evidence · p50 · p95 · reranked), the record as `Facts` (corpus · policy · purpose · the question set as a URI · by status · build · published), the **per-section table** ordered by a *Sort by* `Select` (fact coverage first; a row filters the items), the **items** (question id · section · language · status word beside its dot · facts `hits/total` or *false evidence · clean* for a negative · cited page · latency · reason codes as `xs` chips). `?section=` keeps one section's items, named by a removable `Chip` — what a dashboard's section row deep-links to. The chips are words: *Indicative* (`warn`) while any row is `llm_proposed` with the note *indicative until reviewed* (TBD-916, never a floor); `⚠ reranker` (`warn`) when the reranker was away on more than 5 % of the rows, with the note that the run is left out of comparisons; *Revoked* (`muted`). **An external benchmark run is one more row:** a *Bench* chip (`neutral`) names the dataset (`mine1` · `multiconer_v2` · …), the corpus cell reads the dataset pin (`mine1@0089147b…`) and links nowhere — the dataset was purged after the run; the run page carries the external note (`graph.bench.external.note`); `⚠ judge` (`warn`) when the judge route was away on more than 5 % of the rows, the twin of `⚠ reranker`, with the same *left out of comparisons* note. Every cell is an id, a code or a number the server computed; the pages never see a question, a gold fact, a dataset sentence or an answer. Read-only — nobody edits a measurement. **:** on an external run only, a ***Bench metrics*** `Facts` block under the seven numbers — one fact per non-null metric_set column of the run (`graph.bench.metric.*`, uk = en), the published reference systems' numbers beside it in `nexus-cc-muted` (*0,41 · xlmr_large 0,61 · xlmr_base 0,66*; `unmapped` is a count, summed); a platform run shows no block. ***suspect*** (`warn`, (a)) on both pages when every measured, non-reference row returned nothing, with the note *a harness fault until proven otherwise* and the five means greyed (`BenchStats[data-suspect]`) — computed by the server at read time (`counts.harness_suspect`), so a run reached by any door says it. Built on `PageFrame` (DS-3020, dense on the run page), `DataTable` (DS-3030 — no cell override, numbers right-aligned, a caption), `Facts` (DS-3018), `Chip` (DS-3003), `StatusDot` (DS-3004), `Select` (DS-3012), `Toolbar`, `States` (DS-7005 · DS-7006); not a kit duplicate — the kit has no run, no section, no bench.
