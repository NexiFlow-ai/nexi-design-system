**DS-6710** · `apps/factory/src/components/parts/ImportPanel.tsx#ImportPanel` · proposed

Settings › Import: a file of records becomes a *batch* the person reviews, tries, commits and may undo as a whole. **File**: the record type, the Project, a CSV or JSON file ≤ 2 MB / 5 000 rows — *Preview* uploads it once; the bytes are never kept, only the derived rows. **Review**: the proposed mapping per column (a ranker over column names — never a model; every candidate with its score is shown, the person's `Select` is final), the counts *new · update · rejected* as chips, the rejected rows with the reason per field, the first rows with their state as a word. *Dry run* reports what a commit would write and writes nothing (the batch stays previewed); *Commit* asks once (`ActionPanel`) and writes. **Recent batches**: every batch with its state as a word (*previewed · committed · undone · partly undone*), its counts, and *Undo* on a committed one — created rows removed, updated rows restored; a row another actor edited since is named and stays (`ROLLBACK_PARTIAL`), never silently overwritten. A reader sees the recent batches and a `Restriction`; in the connected world the door says the owner is external and offers nothing. Not a kit duplicate: the kit has no upload-review-commit-undo ladder.
