**DS-3066** · `@nexus/ui/workbench#ProviderMark` · adopted

A third party's logo beside its name, in every row that names a provider (the tool door, the Tools tab, NexCore's Connections and Tools, the Inbox card, the briefing): a 28 px square (24 px `sm`) with the kit's grey border and subtle fill, the glyph 20 px (16) inside it **in the brand's colour — the one exception to DS-1003's rule, and only inside the square**; the border and the fill never take the colour, so in Graphite the square reads as a square. No glyph → the monogram of the name. Always `aria-hidden`: the name beside it is the text. The glyph set is the generated Simple Icons subset: `provider` names a slug; a caller's own `glyph` path wins; a provider the set lacks (Slack · Microsoft 365 · OpenAI, removed upstream by the brands) is the monogram by record. amends DS-1050 (*an icon is Lucide; a provider's logo is a ProviderMark*).
