# Nexi Design System

The design system of Nexi: the register (every idiom as one row with its contract and states), the tokens, and the static component workshop served at https://docs.nexiflow.ai/design-system/.

publication pipeline that runs a guard over the whole export before anything is pushed. The export is reproducible:
